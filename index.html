Project details

This project collects stop words for Hindi and Bhojpuri in Devanagari script. A stop word list holds very common words (for example "में", "है", "बा") that NLP pipelines usually remove before analysis. Bhojpuri has few ready-made resources, so this list is meant to help low-resource Indic NLP work.
